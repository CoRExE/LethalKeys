# Changelog

## 0.1.1

- LethalConfig is now a dependency, so the in-game settings menu is installed automatically.
- Added a link to the source code (GitHub).

## 0.1.0

- First release.
- One random keybind is reassigned on each death (keyboard and mouse buttons, conflict-free).
- Changes stack until the crew is fired, and are saved with the run (host: save file, client: per host).
- On-screen messages wait for the HUD to be free. A summary is shown when loading a run.
- Player keybind settings are protected.
- Optional in-game menu with LethalConfig.
